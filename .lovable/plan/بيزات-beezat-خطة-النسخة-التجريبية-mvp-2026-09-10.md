# بيزات (beezat) — خطة النسخة التجريبية MVP

## ملاحظة مهمة حول التقنيات
هذه المنصة تبني تطبيقات React مع Vite (وهذا مطابق لطلبك في الواجهة الأمامية)، لكن الخادم وقاعدة البيانات هنا مبنيان على Lovable Cloud (قاعدة بيانات PostgreSQL + دوال خادم آمنة + تسجيل دخول جاهز) بدل Express و MongoDB. النتيجة النهائية نفسها: واجهة React عربية RTL متصلة بقاعدة بيانات حقيقية، بدون الحاجة لإعداد حسابات خارجية أو ملفات مفاتيح، والنشر يتم بضغطة زر من داخل المنصة. لا يمكن تشغيل Express/MongoDB/Vercel هنا. إن كنت تريد MERN حرفياً فهذا خارج قدرة هذه البيئة.

## هيكل المشروع

```text
src/
  routes/
    index.tsx                 الصفحة الرئيسية (تعريف + بدء الاستبيان)
    questionnaire.tsx         استبيان المخاطر
    result.tsx                نتيجة المخاطرة + المحفظة المقترحة
    portfolio.tsx             تفاصيل المحفظة وإعادة التوازن
    auth.tsx                  تسجيل الدخول/إنشاء حساب
  lib/
    risk.ts                   منطق حساب درجة المخاطرة والعائد المتوقع
    rebalance.ts              خوارزمية إعادة التوازن
    portfolio.functions.ts    دوال الخادم (حفظ/جلب/إعادة توازن)
  components/                 مكونات الواجهة
```

## قاعدة البيانات (بدل Mongoose Models)

- `profiles` — بيانات المستخدم الأساسية
- `risk_assessments` — إجابات الاستبيان + الدرجة + المستوى الناتج
- `model_portfolios` — المحافظ النموذجية (3–5 محافظ إسلامية)
- `portfolio_allocations` — أوزان الصناديق داخل كل محفظة نموذجية
- `user_portfolios` — محفظة المستخدم المختارة ومبلغه
- `holdings` — الأصول المملوكة وقيمتها الحالية
- `rebalance_events` — سجل عمليات إعادة التوازن

كل الجداول محمية بحيث يرى كل مستخدم بياناته فقط، والمحافظ النموذجية للقراءة العامة.

## نقاط الوصول (بدل API Routes)

- `submitRiskAssessment` — استقبال الإجابات، حساب الدرجة، إرجاع المستوى
- `getModelPortfolios` — جلب المحافظ النموذجية وأوزانها
- `selectPortfolio` — ربط المستخدم بمحفظة ومبلغ استثمار
- `getUserPortfolio` — جلب محفظة المستخدم وأصولها
- `checkAndRebalance` — فحص الانحراف وتنفيذ إعادة التوازن وتسجيلها

## المراحل

### المرحلة 1 — الأساس الشغّال (واجهة → قاعدة بيانات)
- تفعيل Lovable Cloud وإنشاء الجداول مع بيانات المحافظ النموذجية الحقيقية
- تسجيل دخول بالبريد وكلمة المرور
- استبيان المخاطر (6–8 أسئلة بلهجة ومواقف كويتية) بواجهة بسيطة جداً
- حساب الدرجة والمستوى والعائد المتوقع وحفظه في قاعدة البيانات
- عرض المحفظة المطابقة وحفظ اختيار المستخدم
- تنسيق أدنى فقط: RTL وخط عربي واضح

بنهايتها: تقدر تسجل، تجاوب الاستبيان، وتشوف محفظتك محفوظة فعلياً.

### المرحلة 2 — المحافظ النموذجية وصفحة المحفظة
- عرض المحافظ الـ3–5 بالتفصيل: الأصول، الأوزان، مستوى المخاطرة، العائد المتوقع
- صفحة محفظة المستخدم مع رسم توزيع الأصول والقيمة الحالية

### المرحلة 3 — إعادة التوازن الدورية
- خوارزمية تقارن الأوزان الحالية بالمستهدفة وتكتشف الانحراف فوق حد معين
- تنفيذ إعادة الضبط وتسجيل العملية وعرض سجل العمليات للمستخدم

### المرحلة 4 — الهوية البصرية والتحسين
- هوية بصرية كويتية مميزة، تحسين العرض على الجوال، وصقل نصوص الاستبيان والنتائج

## حدود العمل
سيتم بناء الميزات الثلاث المطلوبة فقط. الأرقام والعوائد المعروضة تقديرية للعرض التجريبي ولا يوجد تداول حقيقي أو ربط ببنك أو وسيط.
